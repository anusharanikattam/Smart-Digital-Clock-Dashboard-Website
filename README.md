# ⏰ TimeVerse – Smart Digital Clock Dashboard

## Internship Project

### Project Overview

TimeVerse is a Smart Digital Clock Dashboard developed using HTML, CSS, and JavaScript. The project is designed to provide real-time clock functionality along with productivity tools in a modern and user-friendly interface.

The dashboard combines multiple features such as a Digital Clock, Analog Clock, Alarm System, Stopwatch, World Clock, Calendar, To-Do List, and Theme Customization into a single web application.

---

## Objectives

- Develop a responsive web application using front-end technologies.
- Implement real-time clock functionalities.
- Improve productivity through integrated tools.
- Create an attractive and interactive user interface.
- Apply JavaScript concepts in a practical project.
