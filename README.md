# ⏰ Smart Digital Clock Dashboard

A modern and responsive Smart Digital Clock Dashboard built using HTML, CSS, and JavaScript.

## 🚀 Features

* 🕒 Analog Clock
* ⏰ Digital Clock
* 🌦 Weather Dashboard
* 🌍 World Clock
* 🔋 Battery Status
* 🌐 Internet Status
* 🎵 Music Player
* ⏱ Stopwatch
* ✅ Productivity Goals
* 📅 Calendar
* 📱 Responsive Design
* ✨ Smooth Animations
* 🎨 Modern User Interface

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

* index.html
* style.css
* script.js
* README.md

## 🎯 Project Objective

The main objective of this project is to create an all-in-one dashboard that displays time, productivity tools, and useful daily information in a modern and interactive interface.
